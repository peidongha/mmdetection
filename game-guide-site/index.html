DEPLOY READY

买好域名后就能上线

  1. 把 game-guide-site 文件夹上传到 Netlify、Vercel、Cloudflare Pages 或你的服务器。
  2. 平台构建设置选择“静态站点”，无需安装依赖，发布目录填 game-guide-site。
  3. 在域名服务商添加平台提示的 CNAME 或 A 记录，等待 DNS 生效。
