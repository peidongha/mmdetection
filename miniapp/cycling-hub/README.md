# 骑友共创营小程序

“骑友共创营”是一款面向自行车与摩托车骑友的微信小程序 MVP，围绕“改装攻略、骑行路书、社区经验”三个板块构建可持续收益闭环。

## 核心板块

1. **骑行改装攻略**：覆盖自行车与摩托车；自行车进一步细分山地车、公路车、折叠车，按照预算、场景、难度和合规风险推荐升级清单。
2. **骑行路书攻略**：同时支持自行车与摩托车，沉淀路线、补给点、撤退点、油站、住宿、风险提醒和达人收费模板。
3. **社区讨论分享经验**：把问答、改装作业、避坑经验和路书共创沉淀为平台内容资产，并通过积分、采纳奖励和分佣驱动达人持续贡献。

## 创新运营模式

传统骑行社区通常只做内容浏览和闲聊，本方案将“内容”升级为“交易前置服务”：

- **问诊式改装推荐**：先让用户明确车型、预算和使用场景，再推荐攻略、配件与认证门店预约。
- **达人路书共创分佣**：达人发布高质量路书，平台提供结构化模板、审核、付费售卖和结算。
- **本地门店履约网络**：攻略页直接承接安装、保养、救援、试骑等高意向服务线索。
- **社区经验资产化**：优质回答可转化为 FAQ、攻略和付费路书，避免经验只停留在聊天流中。

## 快速部署上线

1. 使用微信开发者工具导入 `miniapp/cycling-hub`。
2. 在 `project.config.json` 中把 `appid` 替换成真实小程序 AppID。
3. 先用当前静态数据完成审核演示和种子用户测试。
4. 上线前接入云开发或自有后端，建议最小数据表：`guides`、`routes`、`posts`、`orders`、`partners`、`users`。
5. 开通微信支付后，优先上线“付费路书”和“预约订金”，最快形成现金流。
